# No affine derivative in any encoded hash coordinate

## Result and limits

This checkpoint proves a function invariant. It produces no faster kernel.
The parent's last validated implementation remains 865 cycles. No kernel,
simulator, test data, memory layout, or ISA behavior was changed.

Let H be the full wrapping 32-bit reference hash. Independently choose
invertible input and output encodings satisfying

    E(x XOR n) = E(x) XOR n  for every n < 2**30.

Equivalently, each encoding has the form

    E(x) = x XOR J(x>>30),

where J is a four-entry word table and its top-two-bit action permutes the
four tags. The low 30 bits undergo a constant XOR translation in each tag.

For g = E_out H E_in^-1, every individual output coordinate g_k, k=0..31,
has NO affine derivative in any nonzero encoded input direction. The same
is true of g_0 XOR g_1. Neither encoding needs to preserve parity, and the
two encoding tables need not agree. Thus the invariant also permits
round-dependent representations.

This is not a proof that every nine-operation hash or every kernel below
850 cycles is impossible. Noncommuting encodings and prefixes whose
relevant low bit has no affine derivative remain outside the corollaries.

## Component coverage

For an output coordinate below bit30, the raw-output function is

    H_k XOR T(H30,H31).

There are eight classes up to complementation, written as

    H_k XOR alpha*H30 XOR beta*H31 XOR eta*(H30 AND H31).

For the top two coordinates, invertibility of the four-tag permutation
allows the three nonzero linear functions of H30,H31, up to complement.
The coordinate sum g0 XOR g1 supplies eight more classes with H0 XOR H1
as the base. The checker covers all 30*8 + 3 + 8 = 251 classes.

The omitted output complements do not change derivatives.

## Recovering the global leading vector

For one Boolean component, let c_t be its restricted degree30 coefficient
and v_t its 30-bit degree29 coefficient vector in raw tag t. Its global
degree31 vector a is

    a_low30 = v_0 XOR v_1 XOR v_2 XOR v_3
    a_30    = c_0 XOR c_2
    a_31    = c_0 XOR c_1.

Every checked component is balanced, so its global degree32 coefficient
is zero. Every one has a nonzero recovered a, proving degree exactly31.

The formula is checked independently against complete Boolean Mobius
transforms in 144 smaller random domains.

## Degree after input encoding

Every covered encoded component also has algebraic degree at least30.
To see this, composing any Boolean polynomial with a raw-node-commuting
encoding can raise its degree by at most one. All nonlinear substitution
terms depend on the same two top-tag variables. A monomial using such a
term loses at least one original coordinate factor, while gaining at
most those two tag factors; a term using no substitution keeps its
original degree.

Writing f = g E_in, the verified raw degree31 therefore implies
degree(g)>=30. This lower bound applies to every individual encoded
coordinate and to g0 XOR g1, for independent input/output tables.

## Low encoded directions

A nonzero direction supported below bit30 is unchanged by conjugation
with E_in. If the encoded derivative were affine, pulling it back through
E_in would produce a raw function in the space generated by a constant,
the 32 raw bits, and the one product x30*x31.

For a degree31 Boolean function with leading vector a, a derivative of
degree at most two must satisfy

    a_i*delta_j XOR a_j*delta_i = 0  for every i,j.

These are its degree30 coefficients. Since a is nonzero, the only possible
nonzero direction is delta=a.

In 188 classes, a has a nonzero top-two-bit part and is therefore not a
low direction. The remaining 63 classes have a unique candidate low
direction. Its derivative values at zero, the 32 unit vectors, and the
top-bit pair fix every coefficient of the putative raw-affine-plus-product
function. A further exact witness contradicts it. Every stored low
witness is at most12.

## High encoded directions

A high encoded direction pairs the four raw input tags. On any paired
tags A,B, the raw low inputs differ by some fixed XOR translation delta.
An affine encoded derivative would require

    f_B(u XOR delta) = f_A(u) XOR linear(u) XOR constant.

Thus their degree30 coefficients must agree. If that coefficient is zero,
their degree29 vectors must agree as well. If it is one, translation of
the full monomial fixes the ONLY possible translation:

    delta = v_A XOR v_B.

The checker evaluates zero and the 30 low unit vectors to determine the
putative affine difference, then rejects it with an additional exact
witness. The unique-translation equation was separately checked on 144
constructed affine-equivalent smaller pairs.

All SIX raw-tag pairs reject individually for EVERY component. Of the
1506 component/pair cases, 1162 fail a degree-coefficient equality and
344 fail an exact affine-equivalence witness. Every high witness is at
most31. Consequently no tag pairing, and hence no high encoded direction,
can supply an affine derivative.

No result depends on treating an unrejected finite sample set as a proof
of equivalence. A case that survived those samples would remain
unresolved. There are zero unresolved cases.

## Consequences for rotation tails

Let k=32-r, with 1<=k<=31, and let m=2**k times an odd number. The tail

    q = d>>r
    y = m*d + q mod2**32

is a permutation. Writing d=u+2**r*q, its low k output bits are q and
its remaining r output bits are an odd multiple of u. In particular,

    y_k = d_0.

Therefore this tail cannot implement the encoded hash if the preceding
core's required low bit has any affine derivative. This includes the
previously described ordinary-prefix and single-new-low-source circuit
obstructions, now for EVERY k and independent raw-node-commuting
encodings, not only k=1.

When r<31, q has several bits. Its low bit is a potential branch parity,
but q itself is not a Boolean flag. Extracting q AND1 still costs an
instruction unless a separate valid index construction consumes it.
The theorem therefore does not by itself imply a cycle saving.

Constants require distinct statements:

- For y=(m*d+C) XOR q, d0 = y_k XOR C_k for every C. The lower k bits of
  m*d are zero and q occupies only those lower bits.
- For y=m*d+q+C, C divisible by2**k gives the same direct exposed bit.
- For the additive tail with k=1 and C odd,
  d0 = y1 XOR y0 XOR C1 XOR1. The new g0 XOR g1 component closes this case.
- For additive k>1 and unaligned C,
  d0 = y_k XOR C_k XOR [y mod2**k < C mod2**k].
  The nonlinear borrow term is outside this certificate. The actual
  two-instruction shift/MAD tail has C=0.

## Every odd-multiplier one-bit XOR-flag tail

There is an independent short exclusion that needs no ANF assumption on
the preceding core. Consider

    q = d>>31
    y = (m*d+C) XOR q,  m odd,

and require q to be decoded raw output parity, up to a fixed complement.

Let S be the affine image of the lower half of the d domain. An odd
affine permutation maps the upper half to S XOR2**31, which is the
complement of S. The tail's q=0 outputs are S, and its q=1 outputs are

    complement(S) XOR1 = complement(S XOR1).

Tail bijectivity therefore forces S=S XOR1. Its inverse flag q is
invariant under y XOR1.

Every raw-node-commuting output decoder commutes with XOR1, so decoded
raw parity MUST flip under that same encoded output change. It cannot
equal q or its complement. This closes every odd m and C directly,
without classifying the odd tail multipliers and without restricting
the preceding core beyond what final bijectivity requires.

## Reproduction

The finite package needs only Node.js and its standard library. Run

    node stratified_components.js

to regenerate the classification, check the independent verifier, compare
the compact stored witness certificate, and run the geometry checks.

Optionally run

    node stratified_components.js full_result.json

to save every full component, fitted affine function, and exact witness.
The default run prints the verification summary and writes no files.

The command-line harness was syntax-checked and exercised with in-memory
filesystem substitutes because the workspace execution service was
unavailable. It reproduced the complete classification exactly. The core
classifier, verifier, and geometry checks executed successfully in the
pure-JavaScript environment. Native Node execution can be repeated when
the workspace service recovers.

The compact certificate stores one low witness and six high-pair
witnesses per component; null denotes a degree-coefficient rejection.
All fitted functions and expanded evidence are reconstructed by the
supplied source.
